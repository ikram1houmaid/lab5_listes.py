
# TP5 Python – Les listes et les listes de listes

## Description

Ce TP permet de découvrir et de pratiquer les listes en Python,
ainsi que les listes de listes.

Le travail est réalisé avec le langage Python.

## Objectifs

- Créer et modifier des listes.
- Utiliser append(), insert(), remove() et pop().
- Accéder aux éléments avec les index positifs et négatifs.
- Manipuler les tranches (slicing).
- Créer et parcourir des listes de listes.
- Accéder et modifier les éléments en deux dimensions.
- Trier les listes et calculer des statistiques.
- Effectuer une recherche dans une liste.

## Exercices réalisés

### Étape 1 : Création et modification des listes
Utilisation des méthodes append(), insert(), remove() et pop().

### Étape 2 : Accès par index
Accès aux éléments avec les index positifs et négatifs.

### Étape 3 : Slicing
Extraction de parties d'une liste et inversion d'une liste.

### Étape 4 : Listes de listes
Création d'une classe contenant le nom, l'âge et la note des étudiants.

### Étape 5 : Accès en deux dimensions
Extraction et modification des informations d'un étudiant.

### Étape 6 : Tri et statistiques
Tri des étudiants selon leurs notes et calcul de la moyenne.

### Étape 7 : Recherche
Recherche d'un étudiant par son nom.

## Mini-projet : Gestion simplifiée d'une classe

Développement d'un programme interactif permettant de :

1. Afficher les étudiants.
2. Ajouter un étudiant.
3. Supprimer un étudiant.
4. Modifier les informations d'un étudiant.
5. Calculer les statistiques de la classe.
6. Quitter le programme.

## Technologies utilisées

- Python 3
- Visual Studio Code

## Exécution

Lancer le programme avec la commande :

```bash
python lab5_listes.py
```
